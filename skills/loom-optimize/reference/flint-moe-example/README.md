# Flint (RecursiveSI/flint, 40B MoE) Loom port — reference sources

Snapshot of the hand-tuned MoE port from the original evaluation (build script:
build_int4.py; set FLINT_TOKENIZER and FLINT_GGUF to your own files). To build
it, put every file except build_int4.py and this README into a `program/`
directory next to build_int4.py, which mirrors the original repo layout.
Generated GEMM/MoE code is recreated by gen_gemm.py and gen_moe.py.
Architecture: 49 layers, 32 query / 4 KV heads (head_dim 128), attention sinks,
alternating sliding-window (512) layers, top-k MoE FFN; weights int4 (Q4_1-style)
or GGUF Q4_K_M.

| File | What to learn from it |
|---|---|
| gen_moe.py | router top-k -> per-expert token buckets (with an info buffer) -> grouped expert GEMMs (WMMA, padding-free) -> weighted combine; decode path uses per-token expert matvecs |
| gen_decode.py + decode_base.loom.txt | adaptive split-K decode attention (<=64 splits, ~32 keys/split, idle splits exit early, 16-key unroll, sinks) |
| flash2.loom | transposed prefill flash attention with sinks + sliding window (generated by gen_flash2.py FLASH2_TARGET=flint) |
| layers.loom | per-token RoPE+KV store (flint_qk_rope_store2), listed fallback over live tokens only |
| fused.loom | fused rmsnorm + f16 row scale (one pass feeds the GEMMs) |
| model.loom | the command program: decode vs prefill dispatch per shape |
| control.loom / prepare.loom / storage.loom | glue for a `<|user|>…<|assistant|><think>` chat format |

Measured on Strix Halo vs llama.cpp ROCm (lemonade b1355), int4 build:
decode 99-104 vs 62 tok/s, 32k decode 63 vs 48, 4 streams 181 vs 152,
prefill 2k ~2650 vs 1509, 32k 1976 vs 1047. Correctness: near-ties only vs the
llama.cpp golden, concurrent == sequential outputs.
